IQueueServices

Services for manage queues of an underlaying queue server.

Namespace:
KpokPatagon.Queue
Type:
Interface
Public:
Yes
Protected:
No
Sealed:
No
Abstract:
Yes
Implements:
System.IAsyncDisposable

Example

Service usage:

Inject the service where required:


            readonly IQueusServices _queueServices;
            
            public MyClass(IQueueServices queueServices) 
            { 
                _queueServices = queueServices;
            }
            
            async Task PublishWorkQueueAsync(string name)
            {
                await _queueServices.CreateWorkQueueAsync(name);
            }
            
            async Task DeleteWorkQueueAsync(string name)
            {
                await _queueServices.DeleteWorkQueueAsync(name);
            }
            
            async Task PurgeQueueAsync(string name)
            {
                await _queueServices.PurgeQueueAsync(name);
            }
