IPublisherServices

Services for publishing messages to queues of an uderlaying queue server.

Namespace:
KpokPatagon.Queue
Type:
Interface
Public:
Yes
Protected:
No
Sealed:
No
Abstract:
Yes
Implements:
System.IAsyncDisposable

Example

Service usage:

Inject the service where required:


            readonly IPublisherServices _publisher;
            
            public MyClass(IPublisherServices publisher) 
            { 
                _publisher = publisher;
            }
            
            async Task PublishWorkQueueAsync(string queue, MyModel data)
            {
                await _publisher.PublishWorkQueueAsync(name, data);
            }
